# SecureVPN — เว็บเช่า VPN (ตัวอย่าง)

โปรเจกต์หน้าเว็บสำหรับร้านเช่า VPN สร้างไว้ใช้กับ Nexus Studio / GitHub Pages

## ไฟล์

- `index.html` — หน้าหลัก (ฮีโร่, จุดเด่น, แพ็กเกจ, FAQ, ฟอร์มติดต่อ)
- `css/style.css` — สไตล์ธีมมืด
- `js/script.js` — เมนูมือถือ, เลือกแพ็กเกจ, สร้างข้อความสั่งซื้อ

## วิธีใช้ใน Nexus Studio

1. แตก zip ไปที่ `/sdcard/MiniStudio/ชื่อโปรเจกต์/`
2. เปิดโปรเจกต์ → เปิด `index.html`
3. กดปุ่มตา (Preview) เพื่อดูหน้าเว็บ
4. แก้ข้อความราคา / ชื่อร้าน ใน `index.html` ตามต้องการ
5. Push ขึ้น GitHub แล้วเปิด GitHub Pages เหมือนโปรเจกต์ MyWebsite

## ลิงก์หลังเปิด Pages

`https://<username>.github.io/<repo-name>/`

## หมายเหตุ

- ฟอร์มไม่ได้ส่งเซิร์ฟเวอร์ — จะสร้างข้อความให้คัดลอกไปแชท
- ตัวเลขความเร็วบนการ์ดเป็นค่าจำลองเพื่อโชว์ UI เท่านั้น
- ผู้ให้บริการต้องกำหนดเงื่อนไขการใช้ให้ชัดเจนและถูกกฎหมาย
